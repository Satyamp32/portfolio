How I think through products

ChatGPT Voice Nudge — Full PRD
AI PM Fellowship · NextLeap
48% → 60% voice usage target Nudge CVR >25% +30% voice sessions / 3 mo
Research (n=25)
  • 88% awareness, ~48% regular usage — behavior gap, not discovery
  • 48% feel socially awkward using voice in shared spaces
  • 48% face accent/language recognition issues
  • 44% prefer typing for control and editability
Solution
  • Contextual voice nudges — intent-triggered, non-intrusive
  • Trigger logic: query length + context signals above threshold
  • Adaptive suppression if nudges are dismissed
  • Selected over privacy mode and editability features for faster experimentation
Success Metrics
  • Voice Usage Rate — % active users using voice at least once
  • Nudge Conversion Rate — % nudges leading to voice activation
  • Voice Sessions per User — weekly avg
  • Voice User Retention (7-day)
  • Nudge Dismissal Rate
