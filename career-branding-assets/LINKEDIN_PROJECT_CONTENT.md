## Project 1: AI Agent Workflows & Automation
**Headline:** Just deployed a 4-phase AI agent architecture using the Model Context Protocol (MCP) to fully automate reporting workflows! 🚀

**Content:**
Data synthesis and reporting often become a bottleneck for leadership teams. To solve this, I designed and deployed an end-to-end AI agent system integrating the Model Context Protocol (MCP) directly with Google Workspace. 

We automated the entire workflow from data analysis to final report generation via Google Docs and email. By architecting a robust 4-phase system with secure OAuth 2.0, we’ve completely eliminated the manual overhead of reporting.

*Key Takeaways:*
🔹 Systems thinking is just as important as the LLM model itself.
🔹 Automation architectures need scalable auth and monitoring (Phase 4 is all about production readiness!).
🔹 The future of PM is technical orchestration—connecting AI intent to measurable business actions.

## Project 2: Zomato AI Semantic Search
**Headline:** How do we make search understand intent, not just keywords? I built an AI Assistant for Zomato to solve exactly that. 🍔💡

**Content:**
Have you ever searched for "healthy dinner under ₹300 in Indiranagar" and gotten zero results because traditional search engines only look for exact keyword matches? 

I recently led a full-stack project to build an AI-powered semantic search engine for Zomato. We focused on NLP intent parsing to deeply understand hyper-local context and dietary preferences. Deployed on Vercel and Railway, this engine reduced zero-result rates by 40% in testing. 

*Product Lessons:*
📍 AI should solve friction, not just be a feature. 
📍 Discovery optimization directly drives conversion and GMV.
📍 Bridging the gap between a user's natural language and a structured database is the ultimate PM challenge.
