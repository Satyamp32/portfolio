# Project Bullet Points (STAR Format)

## MCP Google Docs Integration
* **Situation:** Manual data analysis and reporting processes were creating bottlenecks for leadership teams.
* **Task:** Design a scalable, secure, and automated reporting pipeline using AI agents.
* **Action:** Architected a 4-phase AI agent system utilizing the Model Context Protocol (MCP), successfully integrating OAuth 2.0 for secure Google Workspace connections, and automating email notifications for production monitoring.
* **Result:** Achieved 100% automation in report generation, drastically reducing manual synthesis time and establishing a production-ready AI workflow.

## Zomato AI Assistant
* **Situation:** Users faced high friction and zero-result rates when using natural language or complex constraints in restaurant searches.
* **Task:** Improve discovery and search-to-order conversion by interpreting user intent accurately.
* **Action:** Led the full-stack development and Vercel/Railway deployment of an AI recommendation engine utilizing NLP for semantic parsing (e.g., extracting price, location, and cuisine intent).
* **Result:** Reduced the zero-result search rate by 40%, significantly optimizing the top-of-funnel conversion funnel for consumer discovery.

## ChatGPT Voice Nudge System
* **Situation:** Despite high awareness (88%), regular usage of ChatGPT voice features was lagging at ~48% due to behavioral and environmental friction.
* **Task:** Increase voice adoption through seamless, contextual product interventions.
* **Action:** Conducted a 25-user research study to uncover behavioral gaps, then designed an adaptive voice nudge system triggered by query intent and length, documented in a rigorous PRD.
* **Result:** Set a target for a 60% conversion lift, establishing clear A/B testing methodologies and defining critical retention metrics for voice sessions.
